# Harin (하린 · 夏凜) — TOPIK I (1급–2급) Korean Studio

**Harin (하린)** is the Korean TOPIK I sister platform to [Haruka](https://github.com/VonMAd/Haruka) — built as a 100% self-contained, single-file, zero-CDN web application with a unique **Goryeo Cheongja (Celadon Porcelain) & Dalbit Hanok (Moonlight Lacquer)** visual design.

## Live Studio
- **GitHub Pages:** https://vonmad.github.io/Harin/
- **Offline Single File:** Download [`Harin.html`](./Harin.html) and open it in any modern browser — no server, no build step, and no API key required.

## What's Inside (9 Mastery Modules)
1. **Study Path & Smart SRS (`HarinSRS`)** — 5-Stage, 20-Milestone progressive TOPIK I roadmap with Leitner 5-Box spaced repetition, daily XP targets, and streak combos.
2. **Hangul Studio (한글)** — 86 Jamo, double consonants, compound vowels, and syllable blocks with a 4-quadrant Korean calligraphy writing pad and interactive quiz.
3. **Batchim & Sound Rules (받침)** — 86 final consonants, double batchim, and phonological rules (연음, 비음화, 구개음화, 경음화) with audio drills.
4. **Hanja Word Roots (한자어)** — 383 categorized Sino-Korean roots (`1급` & `2급`) with Eum-Hun readings, compound words, typing recall, and 3-mode quiz.
5. **Grammar Lab (문법)** — 169 TOPIK I patterns with usage notes, spoken examples, multiple-choice quizzes, and interactive Korean Sentence Builder.
6. **Vocabulary & Conjugation Studio (어휘)** — 1,550+ graded TOPIK I words across 16 categories with 3D flashcards, **Korean Conjugation Studio (`해요체` / `합쇼체` + irregular verbs `ㅂ`/`ㄷ`/`ㅅ`/`ㄹ`/`르`/`ㅡ`/`ㅎ`)**, Active/Passive pairs, interactive typing drill, and 4-mode quiz.
7. **Reading Lab (읽기)** — 30 graded TOPIK I passages (`R01–R30`) with interactive inline `{word|gloss}` study hints and comprehension quiz.
8. **Listening Lab (듣기)** — 30 graded TOPIK I listening scenarios (`L01–L30`) with toggleable scripts and exam simulator.
9. **TOPIK I Mock Exam (200-Point Timed Simulator)** — Listening (`100 pts`) + Reading (`100 pts`) with official pass thresholds (`1급 ≥ 80/200`, `2급 ≥ 140/200`), mistake review, and auto-SRS scheduling.

## Built-in Korean Woman Voice (Zero API Required)
- Works out of the box with native Seoul Korean woman audio, local browser neural Korean voices (`SunHi` / `Google 한국의` / `Yuna`), and a **100% offline Web Audio API grown-woman vocal-tract formant synthesizer**.
- Optional cloud TTS support (Google Cloud, OpenAI, Azure, ElevenLabs) with **RAM-only session key security mode** and zero-leak single-file export.

- Local-only progress storage with prototype-pollution-safe JSON backup Export/Import and 12 unlockable Korean **Dojang (도장)** achievement seals.
